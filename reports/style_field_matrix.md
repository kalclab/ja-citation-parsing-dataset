# スタイル×文献タイプ別 出力フィールド対応表

`ref_strings.jsonl`（988 レコード × 7 スタイル = 6,916 文字列、全件 generation ok）を対象に、生成に投入した `ja_bib_derived.bib` の各フィールド値が出力文字列に現れるかを実測した対応表。評価設計（どのフィールドがどのスタイルで復元可能か・スコアリング対象にすべきか）の基礎資料とする。

- 集計スクリプト: `scripts/analyze_field_rendering.py`（フィールド別の正規化つき包含判定。NFKC・casefold・空白除去・ダッシュ統一・引用符除去のうえ、著者は筆頭名の姓＋名/イニシャル、数値は桁境界つきで判定）
- 検出率が 0% / 100% でないセルは、個別レコードの目視照合で「条件付き出力」か「判定の副作用」かを切り分けて脚注化した。
- 対応表の author / editor / translator の判定は**筆頭名基準**（筆頭の姓＋名が現れれば ●）。共著者リストの省略は別途、末尾名の出現有無で全レコード検査した（「名前リストの省略」の節を参照）。

凡例: ● = 常に出力 / △ = 条件付き出力（脚注） / — = 出力されない。フィールド名の後の (n) は当該フィールドを持つレコード数。

## 全スタイル共通で出力されないフィールド

`issn`・`ncid`・`yomi`（整列キー）はどのスタイルも出力しない。`@article` の `publisher`（J-Stage 由来の発行機関、74 件）も全スタイル未出力。したがってこれらは文字列からの抽出評価の対象にならない（文字列中に情報が存在しない）。

## 名前リストの省略（et al. 相当）

author / editor / translator の各リストについて、**末尾の名前**が出力に現れるかを全レコード（複数名 955 件超）で検査した結果。省略は名前リストの人数のみで決まり、フィールド種別（著者・編者・訳者）を問わず同じ規則が適用される。

| スタイル | 規則（実測） | 該当件数 |
|---|---|---|
| chicago-author-date | **7 名以上で先頭 3 名＋「ほか」** に省略（6 名以下は全列挙） | author 30 件、editor 1 件（bok0190、9 名）、translator 1 件（bok0162、19 名） |
| jecon-mod | **9 名以上で先頭 3 名＋「他」** に省略（8 名以下は全列挙） | author 11 件、editor 1 件（bok0190）、translator 1 件（bok0162） |
| ipsjsort / jsai / jplain / sist02 / jpa2022 | 省略なし（本データ最大の 20 名まで全列挙） | — |

- 例（art0025、7 名）: chicago `加野芳正, 陣内靖彦, 久冨善之, ほか.`、他スタイルは 7 名全員を列挙。
- 例（art0233、9 名）: jecon-mod `荒木賢二・大橋克洋・山崎俊司他`。
- 本データの名前リストは最大 20 名であり、それを超える場合の挙動（jpa2022 の APA 系規則が想定する 21 名以上での省略など）は未検証。
- 評価設計上の含意: chicago / jecon-mod の該当レコードでは、**4 人目以降の共著者は文字列中に存在しない**ため、著者フィールドの完全一致評価は原理的に不可能。省略記号（ほか／他）の扱いを評価仕様で定める必要がある。

## 評価設計に関わる表層変換（フィールドは出力されるが値が変形するもの）

- **著者名の整形**: jecon-mod は日本語著者を姓名連結＋中黒区切り（`井上絢翔・韓東力`）、jsai は「姓 名」分かち、ipsjsort / jsai / jpa2022 はローマ字名の名をイニシャル化（`Mohr, K.`）。chicago / jplain はローマ字名を自然順（`Klaus Mohr`）に戻す。
- **引用符のロケール変換**: chicago / jpa2022 は題目中の `“...”` を `『...』`／`「...」` に置換する（例 art0127）。sist02 は inproceedings の題目を `“...”` で囲む。
- **ページ範囲の短縮**: chicago は終端ページを短縮する（`124–125` → `124–25`、`1_13-1_22` → `1_13–22`）。
- **英字小文字化**: jplain は題目の英字を小文字化（既知の挙動、`DATASET.md` 参照）。
- **年の変形**: chicago は `2014年`。同一著者・同一年の並びで jecon-mod / jpa2022 / chicago は曖昧性解消接尾辞（`2025a` / `2025b`）を付す。year 欠落の misc 108 件では jpa2022 が `(日付なし)`、chicago が `日付なし` を出力する。
- **巻号の書式差**: `第N巻・第N号`（jecon、jplain/jsai の inproceedings）と `Vol. N, No. N`（ipsjsort、jplain/jsai の article）、`N(N)`（jpa2022）、`N (N):`（chicago）、`vol. N, no. N`（sist02）が混在する。
- **DOI/URL の書式差**: `DOI: 10.x`（jecon）、`（オンライン），10.x`（ipsjsort）、`https://doi.org/10.x`（jpa2022 / chicago / sist02 は url 値）。
- **個別の欠落（1 件）**: inp0222 の著者 `シャザダ&middot;ナイヤール ジハン`（ソース由来の HTML 実体が残存）は、**全 7 スタイルで名部分が脱落し姓「ジハン」のみ**出力される（.bst 側は生の `&` が TeX で破棄され、CSL 側も名が出力されない）。
